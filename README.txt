FITBEAT — FINAL NEW PROJECT PACKAGE
===================================
This ZIP is a standalone NEW GitHub Pages project. It does not need the old Mid-pro- repository.

INSTALLATION
1. Create a new PUBLIC GitHub repository (for example: fitbeat-final).
2. Choose Add file > Upload files.
3. Upload index.html, game.js, style.css, controller.html, .nojekyll, and the entire assets folder to the ROOT of the new repository.
4. Commit changes.
5. Go to Settings > Pages > Deploy from a branch > main / (root) > Save.
6. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
7. For the first test, use keyboard controls.

INCLUDED
- Seven distinct, locally bundled illustrated stage images:
  Warm-up, Light, Moderate, Vigorous, Maximum, Interval, Cool-down.
- Home, Exercise Selection, How to Play & Setup, Settings, Progress, Gameplay, Results.
- No mascot and no NEXT panel.
- Left/right arm lanes; compact rectangular hit zones; four circular motion icons.
- Score, combo, accuracy, estimated calories, pause, retry, volume controls.
- Keyboard: LEFT 1 Up / 2 Side / 3 Twist / 4 Down;
            RIGHT Q Up / W Side / E Twist / R Down.
- Original synthesized metronome beat; no copyrighted music.

IMPORTANT LIMITATIONS
- The seven images are crops of a composite illustration and not full-size standalone 16:9 scenes.
- The home page uses CSS artwork, not the previously approved 3D gym reference.
- Webcam pose detection is experimental. TWIST & PUNCH classification is approximate.
- Phone motion is an experimental assist; it is NOT an independently validated controller.
- Internet is needed for MediaPipe and PeerJS; HTTPS/localhost required for camera.
- No real physical webcam/iPhone acceptance test has been completed.
- Static source and ZIP validation completed; full interactive browser testing was blocked by the execution environment.

Estimated calories: MET * 3.5 * weight(kg) / 200 * duration(minutes).
