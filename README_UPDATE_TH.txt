FITBEAT 7-MODE UPDATE — 2026-11-04

อัปโหลดไฟล์ทั้งหมดใน ZIP ไปยัง root ของ GitHub Pages repository โดยคงโฟลเดอร์ assets ไว้

อัปเดต: 4 Beats = 1 จังหวะ; โปรแกรม 7 ระดับตามที่ตกลง; TWIST/PUNCH ถูกแทนด้วย JACK; ไอคอนปรบมือทั้งสองเลน; เอฟเฟกต์ JUMP!; กล้องตรวจจับตำแหน่งมือ; โทรศัพท์ถือในมือข้างหนึ่ง; Interval สลับช่วงเบา/หนักทุก 30 วินาที

Jumping Jack: เกมให้คะแนนจากแขนยกขึ้นและลดลงครบวงจร ไม่บังคับตรวจจับการกระโดดจริง

คีย์ทดสอบ: มือซ้าย 1 UP, 2 SIDE, 3 JACK, 4 DOWN; มือขวา Q UP, W SIDE, E JACK, R DOWN

หมายเหตุ: โทรศัพท์ใช้ PeerJS ผ่านอินเทอร์เน็ตและเซนเซอร์ส่งข้อมูลช่วยตรวจสอบ แต่ยังไม่ได้ใช้ accelerometer เป็นตัวตัดสินท่าด้วยตัวเอง ต้องทดสอบจริงกับ iPhone/Windows และอนุญาต motion sensor. Firebase cloud sync ต้องตั้งค่า firebase-config.js ตาม README เดิม.

เพลง: คงเพลง OGG ที่สร้างไว้ในเวอร์ชันก่อน ยังไม่ได้ทำเพลงใหม่เลียนแบบลิงก์ YouTube เพราะไม่สามารถยืนยันรายละเอียดเสียงต้นฉบับได้ และไม่ได้นำเสียงจาก YouTube มาใช้

ข้อจำกัด: โปรแกรมลำดับยาวจะถูกตัดเมื่อหมดเวลาของระดับนั้น และความเร็ว Maximum อาจเร็วเกินไปสำหรับการติดตามผ่านกล้อง. ยังไม่ได้ทดสอบกับกล้องและโทรศัพท์จริง
